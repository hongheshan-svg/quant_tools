# daily_stock_analysis 全面补齐实施与验收（2026-10-02）

本次落实用户要求的现有 A 股、国内 ETF/指数范围，以 [daily_stock_analysis 的 be148f39](https://github.com/ZhuLinsen/daily_stock_analysis/commit/be148f39ce3be8bc7f9c2d5b0ad77cd31655e78f) 为固定参考。对应[本次修改前复核](dsa_alignment_review_2026-10-02.md)的 D / S / U / A / O 编号逐项实现，保留已有主线、涨停、交易记账、自学习及通知能力。以上为推送前的本地验收记录；远端工作流状态以 GitHub 实际运行为准，未修改远端仓库设置。

技术栈继续采用 FastAPI、Pydantic、SQLAlchemy、SQLite、React、TypeScript、Vite、Tailwind、Zustand、Electron、LiteLLM / OpenAI SDK。双方主体架构已经一致；本地较新的依赖、YAML 配置、fetch 客户端和现有主题实现保留。LiteLLM 约束同步排除 1.82.7、1.82.8。新增行为进入 Web、API、Docker 和桌面打包资源。

## 使用与兼容

在【数据源状态 → 来源与优先级】调整回退顺序、请求/数据集/整条采集预算和付费源凭证；默认请求 15 秒、数据集 60 秒、整条采集 240 秒。行情页【刷新复权历史】可修订已有价格并保留旧版本；不会在刷新失败时删除旧日线。

在【设置 → 选股策略】编辑评分、补数、模型与风险配置。正式评分文件缺失时读取 `.example`；设置保存只允许 `config/` 内路径。升级同步默认示例，不覆盖已有正式策略文件。新增表和列由 `init_db()` 安全增补，不改列名或删除旧数据；旧报告、会话和后验保留可读。

海外市场、多币种持仓和本地 CLI 模型后端继续按用户确认不纳入本次。长期来源可用率、付费权限、实际策略收益和发行公证需要各自真实运行证据，不能用代码存在或一次验收替代。
