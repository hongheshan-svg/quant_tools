## 刻意未移植与待决定

- **TickPlus（09730e47）**：上游把它接为 A 股和 ETF 的默认首选行情源，说明里带推荐与合作链接，本仓库也没有可用的 Key 验证接口质量和数据口径。现有回退链（腾讯 → 东方财富 → 新浪 → efinance → 通达信）工作正常，不为一个未验证的商业源改变默认顺序。需要时可以作为可选源、默认放在末尾接入。
- **fastapi-guard（b19d4b99）**：上游默认关闭的可选中间件。本仓库已有登录失败限速、未开登录时只允许本机访问、Bearer Token 校验，不为默认关闭的功能新增依赖。
- **DB 单例重新绑定（a52c325f）**：本仓库 `db.py` 的单例是「第一次 `init_db(path)` 生效」，且很多服务在配置为 `{}` 时默认用 `data/quant.db`。照搬「请求不同路径就重新绑定」会让这些服务把测试或临时库切回真实的 `data/quant.db`，风险大于收益。
- **Codex App Server（88ec4bae）**：上游移除了实验性的 App Server 智能体后端。本仓库有对应的只读问股集成（`src/services/codex_runtime.py`、`api/v1/integrations.py`、集成页「Codex App Server 只读问股」），是否同样移除由维护者决定，本次保持不变。
